01玩法

只有三个动词，而且只有一个需要你按。

没做滑铲、冲刺、攻击。每加一个动词之前我都会先问一句：它是让跳跃更深，还是只是多了一个按钮。目前答案是后者，所以都没加。

动词 01

跑（自动）

不用按。速度从 380 一路上到 620，关卡里线性爬升，同一关的节奏是固定的。

动词 02

跳（蓄力）

按住蓄力，松手起跳。轻点是一个小跳，按住是能跨两条东西的高跳。这是游戏唯一的深度。

动词 03

二段跳（补偿）

落地前可以用一次，专门用来救「跳短了」。它不是额外的机动手段，是给判断失误的一次机会。

0.22s蓄满所需
0.09s郊狼时间（走出边缘后还能跳）
0.12s输入缓冲（落地前按的也算）
1次每次离地可用的二段跳

后两个数字是「防手滑」用的。玩家几乎不会察觉，但少了它们，同一个操作会觉得「这游戏不接我的招」——手感大部分是这种看不见的东西撑起来的。

02关卡

五关，一关比一关快，颜色也跟着天亮。

把关卡切成五段，是因为无尽模式里地形每次都不一样，玩家永远学不会任何东西。切成关卡之后每关固定种子，同一条地形可以练五遍，进步就变得可感知。

01霓虹起步120 m380→440深夜霓虹
02横越断口150 m420→490霓虹 → 黄昏
03尖刺地带170 m460→520紫红黄昏
04高层步道190 m490→560黄昏 → 黎明
05终局疾驰210 m520→600熔金黎明
∞无尽疾驰封顶380→620天色循环

通关 = 撞到终点门，冻结世界，结算用时和死亡数。五关过了进无尽模式，最高米数存在 best.json 里。
天空、楼群、角色、HUD 全部从同一套调色里取色，所以「天亮了」这件事本身就是进度条。

03陷阱

三档威胁，看高度就知道该按多久。

最早那版把刺塞在地块中间，跨过缺口落地之后只剩几十像素就要起跳，等于随机死亡——所以障碍一直不敢放密。这一版把陷阱挪到地形本来就要起跳的位置：块尾崖边。

74 px · 必须蓄力

高刺

最小跳只有 90px 的顶点，但它在刺左边就会开始下落，所以必须真按下去。游戏里最纯粹的「判断」。

贴地 · 左右巡 45px

往复锯

很矮，任何一跳都能过去——但它在一个 1.5 秒的周期里左右扫。你要看相位，而不是看距离。

34 px · 或绕行

矮刺 + 平台

轻点就过，起的是节拍作用。约 42% 的刺块上方留了一条单向平台，可以从下面穿上去踩着走——另一条解法。

带陷阱的地面块会被强行加宽到「陷阱宽 + 560」，保证跨过缺口落地之后还有一整段跑蓄力的距离。
落进缺口也不再是软着陆：底下铺了刺床，同时断口立面判「撞上侧面」。

难度靠速度和缺口递进，不靠堆障碍。 — docs/design.md · 设计一页纸

公平性不靠眼估。自测里的自动驾驶按「先定松手点、再反算蓄力、最后校验到刺左沿时已经抬到刺高」这套规则跑五关，要求 5 关 0 死亡；跑不通就说明地形里有不可解的布点，参数必须改。当前结果：28.9 / 32.7 / 34.4 / 35.9 / 37.3 秒，0 死亡。

04更新

做了什么，为什么这么做。

这游戏是从零手搭的，没有策划案、没有美术，一天一版。下面每一条都能对应到代码里的一段。

11-21v0.5

陷阱，和一次坐标系的清算

加了往复锯、把刺抬到 74px、缺口底下铺刺床。真正花时间的是一个潜伏的 bug：刺的坐标存的是世界坐标，绘制和碰撞却按「块偏移」在用，等于多加了一次块位置——所以刺从来没被画在它真正在的地方。修完之后，前面所有的调参才有意义。

后来又补了一刀判定。郊狼时间窗（离地 0.09 秒内还能起跳）本来是为了「自己走下平台不至于冤死」，但它也把「自己跳出去」算了进去：起跳后马上再按一下，会被当成还在地上蓄力——二段跳没了，松手时还把空中的速度重算了一遍，按住不放甚至能白赚一段高度。现在这个窗口只给被动离地；跳出去的再按，就是干脆的一次二段跳。顺带把输入改成每帧采样键状态，切出窗口丢了 keyup 也不会让蓄力条卡在满格。

闪退这种问题没法靠猜。本地拿随机按键压了 9 万帧、exe 空跑两分钟内存不涨，也没复现出来——那就先让它留下证据：启动、每次死亡、每 5 秒一次心跳、退出原因，真崩了连堆栈一起写进 exe 旁边的 run.log。日志不修 bug，但能让下一次闪退有据可查，而不是一句「它就没了」。

11-20v0.4

关卡与终点门

把无限跑切成五关，每关固定种子；加了终点门、通关结算、无尽解锁。顺手修了「终点门悬在缺口上方」——现在门底下那块地面会直接补长，门永远站在实地上。

11-19v0.3

配色

颜色不是装饰，是进度。深夜霓虹 → 紫红黄昏 → 熔金黎明，天色、楼群、尖刺、HUD 全走同一套调色。同时定了一条可读性铁律：能站的用亮边描，会死的用暖色。

11-18v0.2

穿墙

薄平台从下方穿过之后，下落时一定贴回顶面；身体卡进地面块侧面判「撞墙」。试过让平台从下方硬挡，自测立刻变成 12 次死亡——否决了，那种「看不见的天花板」不公平。

05跑起来

它现在只是个本地原型。装两行就能跑。

Python 3.14 有个坑：官方 pygame 还没有 3.14 的预编译包，pip install pygame 会报 from versions: none。装 pygame-ce，社区维护版，代码里照样 import pygame，一行不用改。

01 装依赖

# 3.13 及以下用官方包也行 > python -m pip install pygame-ce # 3.14 只能装 ce 版

02 开跑

> cd D:\游戏原型 > python src\jump_run.py # 无窗口自测 > python src\jump_run.py --selftest 16000
不想敲命令，就直接下这个 exe。 JumpRunner-v0.5.exe · Windows 64 位 · 双击就跑 · 最高分记在 exe 旁边的 best.json
下载 exe · 22 MB 源码 zip · 268 KB

真闪退了别靠猜：exe 旁边会自己写一份 run.log，最后十几行就够定位——启动、每次死亡、每 5 秒一次心跳、退出原因，崩了就带完整堆栈。

操作：按住空格 / ↑ / W / 左键蓄力，松开起跳，空中再按一次是二段跳。Esc 退出。死在哪儿就从哪一关重来，地形不变。

06还没做的

写在这里，免得看起来比实际更完整。

  • 没有音效，一点都没有
  • 没有美术，全部是矩形和三角形
  • 没有关卡选择菜单，每次从第 1 关开始
  • 没有存档续关，只存无尽模式的最高米数
  • 手机不能玩，只有一个键盘版本
  • 抖音小游戏跑 JS/TS，这版还不能直接上平台

    • 下一步不是加内容，是先确认「按住时长 = 跳跃距离」这件事玩家读不读得懂。读不懂的话，整套设计要退回去改成固定两档跳。
